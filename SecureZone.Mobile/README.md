# SecureZone Mobile

React Native / Expo presentation shell for the SecureZone mobile application.

The current implementation intentionally contains visual-only login and personal QR access screens.
The QR pattern and employee details are static presentation fixtures. Authentication, API calls,
QR token generation, token storage, role routing, password recovery and navigation are outside this
change.

## Local preview

```powershell
pnpm install
pnpm start
```
